# Portfolio Site

This is the source code for my personal website. I built it to keep track of my projects and share what I'm learning as a developer.

Check it out live here: [natashaaida242.github.io/portfolio](https://natashaaida242.github.io/portfolio/)

## What's in here
* A clean, dark-mode single-page layout with a sticky sidebar.
* Sections for an intro, my background, and project cards.
* Built using basic HTML5 and CSS3 (no heavy frameworks or templates).
